# E-Commerce Product Listing Page

A fully responsive E-Commerce product catalog and shopping cart application built using **HTML5, CSS3, and JavaScript (ES6+)**, featuring **Browser LocalStorage** for cart persistence.

Developed as **Project 3 (Intermediate Level)** for the **CognoRise Infotech Web Development Internship**.

---

## 🚀 Features

- **Product Catalog Grid:** Clean card layout displaying product images, categories, names, and prices.
- **Search & Filter:** Real-time search by product name and category filtering (Electronics, Fashion, Home).
- **Interactive Shopping Cart Drawer:** Live cart summary showing total items and dynamic total price calculation.
- **Quantity & Management:** Increase/decrease item quantities (with edge-case checks) and remove items from the cart.
- **Data Persistence:** Uses `localStorage` so cart items remain saved across page reloads.
- **Responsive Design:** Optimized layout for mobile, tablet, and desktop viewports.

---

## 🛠️ Technologies Used

- **HTML5** (Semantic layout)
- **CSS3** (Flexbox, Grid, Custom Properties, Responsive Styling)
- **JavaScript (ES6+)** (DOM Manipulation, Array Methods, LocalStorage API)
- **FontAwesome** (Icons)
